# MEOW MEOW Café 🐾
React + Vite site. Run: `npm install && npm run dev`. Build: `npm run build`.
## Deploy
Vercel: `npx vercel login` then `npx vercel --prod`. Or Netlify: `npx netlify login` then `npx netlify deploy --prod --dir=dist` (after build).
Or push to GitHub and import the repo on vercel.com or netlify.com (settings are preconfigured).
## Notes
Cart and checkout are front-end only; checkout creates an email order request. Replace placeholder contact details in src/App.jsx. Images are CSS/SVG/emoji art, so nothing can break.
